ABOUT THE PROJECT

Welcome to AnimeVerse

AnimeVerse is a student web development project designed to provide anime fans with a simple and interactive platform to discover and organise their favourite anime.

Our Features

What makes AnimeVerse useful?

🔎

Anime Search

Search anime by title and filter the collection by genre.

⭐

Trending Section

Explore anime sorted by their sample ratings.

❤️

Personal Watchlist

Save favourite anime using browser local storage.

Technologies Used

The tools used to develop this website.

🌐

HTML5

Used to create the structure and content of all six pages.

🎨

CSS3

Used for colours, layout, responsive design and animations.

⚡

JavaScript

Used for search, filters, anime cards and watchlist features.

Project Objective


The main objective of AnimeVerse is to demonstrate the use of HTML, CSS and JavaScript to develop a multi-page, responsive and interactive website. It also provides practical experience with DOM manipulation, event handling and browser local storage.
